## Context

Personal sites get stale when every update feels like design work. This project treats the portfolio as a publishing system instead of a one-off page.

## Approach

The site separates long-lived facts from routed presentation:

- Shared profile, experience, skill, and navigation data lives in one typed module.
- Blog posts and project writeups live as MDX files.
- Route components render indexes and detail pages from that content.
- The visual system uses a compact set of theme tokens and local UI primitives.

## Outcome

The result is a portfolio that is easier to maintain. New writing or project pages can be added by dropping in MDX, while repeated facts stay consistent across the homepage, About page, Contact page, and navigation.
